# AA_App — 30 заданий по модификаторам доступа (C#, ASP.NET Core MVC + SQLite)

## Запуск
1. Установите .NET SDK 8.0 (https://dotnet.microsoft.com/download).
2. В папке проекта выполните:
       dotnet run
3. Откройте http://localhost:5000

SQLite-файл `aa_app.db` создаётся автоматически при первом запуске.

## Как пользоваться
- Главная страница — список заданий 1–30 (карточки и выпадающий список).
- Страница задания — таблица для ввода данных (можно добавлять/удалять строки) и кнопка «Выполнить».
- Задание 30 — готовое приложение колледжа: /Home/College, вход, студенты, преподаватели, группы, журнал, посещаемость, админ-панель.
- Тестовые аккаунты: admin/admin123, teacher/teacher123, student/student123.

## Если установлен другой .NET SDK
В AA_App.csproj замените `net8.0` на свою версию (например `net10.0`) и версию пакета
Microsoft.EntityFrameworkCore.Sqlite на соответствующую (10.0.x).
